# Secure File Drop System

## Installation
1. Install Python 3.11+
2. Run: pip install -r requirements.txt
3. Run: python app.py
4. Open: http://localhost:5000

## Security Features
- AES-256-GCM Encryption
- One-time download links
- Automatic expiration
- No keys stored on server
